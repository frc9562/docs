Welcome to The Royal Robotics Wiki, a source for all documentation for the Bishop Reding First Robotics Team (Team 9562).  This Site make use of Markdown noted created and formatted in [Obsidian](https://obsidian.md/) and publish to the rest of the team via [Quartz](https://github.com/jackyzha0/quartz).

Generally notes are sorted into 5 categories: 
- [[00 - Quick Notes/index|]] [[00 - Quick Notes/index|00 - Quick Notes]] stores any unsorted notes
- [[10 - Sub Team/index|10 - Sub Team]] stores all general notes for each sub team that apply to every year
- [[20 - Seasonal/index|20 - Seasonal]] stores all notes that only apply to the build season, sorted by sub team (might edit later)
- [[30 - Hardware/index|30 - Hardware]] stores all notes about any purchase hardware for the robot (need to create folder sub categories still)
- [[40 - Team/index|40 - Team]] stores all notes about the whole team (isn't confirmed yet)

For more information about how these doc are created, go visit the [[10 - Sub Team/15 - Documentation/index|Documentation]] page for details.
